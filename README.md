# 궤적 기반 4채널 실시간 렌더링

## 준비

권장 환경은 Python 3.11입니다. NumPy, PortAudio 기반 `sounddevice`, Tkinter가 필요합니다.

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

Windows에서는 가상환경 활성화를 `\.venv\Scripts\activate`로 바꾸고 실행은 동일하게 `python main.py`입니다.

macOS에서 `PortAudio` 관련 오류가 있으면 `brew install portaudio`를 먼저 실행하세요.

## 입력

GUI의 각 탭에서 다음 파일을 선택할 수 있습니다.

- 궤적 CSV: `frame,time_s,azimuth_deg,elevation_deg,distance_m,source`
- 이동 음원: WAV, FLAC 또는 OGG
- 채널 테스트 음원: WAV

CSV 열 이름이 제공 형식과 다르면 프로그램이 누락 열과 실제 열 이름을 오류로 표시합니다.

## 사용

1. `출력 확인`에서 출력 장치를 선택합니다.
2. 스피커–실제 채널 매핑과 각 볼륨을 확인한 뒤 출력 모드를 선택합니다.
3. `설정 저장`으로 `config.json`에 상태를 저장합니다.
4. `재생`에서 궤적 CSV와 이동 음원을 선택하고 재생합니다.
5. `청감 보정`에서 패닝, 고도, 거리 및 효과를 실시간 조절합니다.

설정은 다음 실행에서 자동으로 불러옵니다.

## 청취 체크리스트

### 스피커

- FL을 실제 장치의 왼쪽 앞 스피커에, FR을 오른쪽 앞에 배치합니다.
- RL은 왼쪽 뒤, RR은 오른쪽 뒤에 배치합니다.
- 방위가 정확히 -30°, 30°, -135°, 135°일 때 대응 스피커에서만 소리가 나는지 확인합니다.
- 정면 0°에서 FL과 FR의 음량이 서로 균등한지 확인합니다.
- ±179° 근처에서 끊김 없이 반대편 대각선 쌍으로 이어지는지 확인합니다.

### 이어폰

- FL과 RL은 왼쪽 채널, FR과 RR은 오른쪽 채널로 합성됩니다.
- 정면 위치에서는 양쪽 밸런스를 확인합니다.
- 멀어지는 소리에서 거리 감쇠와 고역 감쇠가 자연스러운지 확인합니다.

### 공통

- 재생 중 화면의 현재 위치와 게인이 실시간으로 갱신되는지 확인합니다.
- `±1 클리핑` 경고가 뜨면 전체 또는 스피커 볼륨을 낮춥니다.
- 언더런 경고가 반복되면 blocksize를 키우거나 장치 latency를 `high`로 변경합니다.
- 도플러는 기본값으로 꺼져 있으며 체크박스로 켤 수 있습니다.

## 1단계: 4채널 출력 확인

출력 확인 탭에서 다음 기능을 사용할 수 있습니다.

- USB 사운드카드 등 출력 장치 선택과 최대 출력 채널 수 확인
- 4채널 미만 장치 선택 시 테스트 차단
- FL, FR, RL, RR 스피커를 실제 출력 채널 1–4에 매핑
- 각 스피커 볼륨과 전체 볼륨을 재생 중 부드럽게 조절
- 채널 1→2→3→4 순차 테스트 및 테스트 정지
- 출력 장치, 매핑, 볼륨, blocksize, latency를 `config.json`에 저장

테스트 전에 앰프와 스피커 볼륨을 낮추고 시작하세요. 기본 볼륨은 스피커별 -12 dB, 전체 -24 dB로 설정됩니다.

## 2단계: 영상 위치를 방위각과 고도로 변환

`영상 및 방향 계산` 탭에서 영상을 열고 프레임을 탐색할 수 있습니다.

- 가로 화각은 사용자가 입력하며 기본값은 90°입니다.
- 세로 화각은 가로 화각과 영상 종횡비로 자동 계산됩니다.
- 화면 중앙은 방위각 0°, 고도 0°입니다.
- 오른쪽은 양의 방위각, 위쪽은 양의 고도입니다.
- 좌우 방향키 또는 이전/다음 프레임 버튼으로 프레임을 이동합니다.

### 좌표 계산

화면 픽셀 좌표를 다음처럼 정규화합니다.

- $n_x = 2x/width - 1$
- $n_y = 1 - 2y/height$

가로·세로 화각을 각각 $H$, $V$라 하면 pin-hole 기하학으로 계산합니다.

- $azimuth = atan(n_x \tan(H/2))$
- $elevation = atan(n_y \tan(V/2))$
- $V = 2 atan(\tan(H/2) \times height/width)$

따라서 단순한 화면폭 곱셈이 아니라 실제 카메라 투영 각도를 계산합니다.

## 3단계: 키프레임 기반 객체 동선

`영상 및 방향 계산` 탭에서 다음 동선 작업을 수행할 수 있습니다.

1. `기준 위치 클릭`을 선택한 뒤 화면에서 기준 위치를 지정합니다.
2. 기준 정면 각도를 입력합니다. 기본값은 0°입니다.
3. `객체 키프레임 클릭`을 선택하고 프레임을 이동하면서 객체 위치를 클릭합니다.
4. 키프레임 테이블에서 프레임, 픽셀 좌표, visible 값을 확인합니다.
5. 비가시 구간의 시작과 끝 프레임을 입력한 뒤 구간 비가시 또는 구간 가시를 적용합니다.
6. 동선 CSV를 저장하거나 기존·신규 CSV를 불러옵니다.

키프레임 사이의 위치는 화면 픽셀 기준으로 선형 보간합니다. 기준 위치와 보간 위치의 픽셀 차이를 이용해 방위각을 계산하며, 오른쪽은 양수, 왼쪽은 음수입니다.

### 3단계 신규 CSV 형식

```csv
frame,time_s,x_px,y_px,azimuth_deg,distance,distance_px,visible
```

- `frame`: 프레임 번호, 0부터 시작
- `time_s`: 프레임/FPS 초
- `x_px`, `y_px`: 원본 영상 픽셀 좌표
- `azimuth_deg`: 기준 정면 기준 방위각
- `distance_px`: 기준 위치와 객체 사이 픽셀 거리
- `distance`: 영상 대각선 길이로 나눈 정규화 거리(0 이상). 실제 미터 단위가 아니며 자동으로 미터로 변환하지 않습니다.
- `visible`: 1은 가시, 0은 비가시

기존 `frame,time_s,azimuth_deg,elevation_deg,distance_m,source` 형식도 불러올 수 있습니다. 기존 CSV에는 화면 픽셀 좌표가 없으므로 픽셀 좌표는 `null`로 처리되며, 방위각과 가시 정보는 호환됩니다.

## 4단계: 음원 관리 및 4채널 렌더링

`음원 및 렌더링` 탭에서 여러 음원을 등록하고 유형과 전달 방식, 프레임 구간을 설정할 수 있습니다.

- DX: 모노를 FL·FR에 각각 -3 dB로 배치합니다.
- FX-Foley: DX와 같은 센터 규칙을 사용합니다.
- FX-Ambience: 입력 음원이 4채널인 경우에만 4채널로 그대로 배치합니다.
- MX-Nondiegetic: 스테레오는 L→FL, R→FR로 배치하고 RL/RR은 각각 -6 dB로 추가합니다. 모노는 FL/FR -3 dB에 가까운 동일 중심 신호로 변환합니다.
- Object: 선택한 동선 CSV의 프레임 visible 값과 방위각을 사용해 기존 패너로 배치합니다.

렌더링은 항상 48000 Hz, 4채널로 합산됩니다. 최종 피크가 1을 초과하면 전체 공통 게인으로 전체 최대 진폭을 1 이하로 낮춥니다. 내보낸 결과는 24-bit PCM 4채널 WAV로 저장되며, 저장 후 채널 수와 샘플레이트를 다시 확인합니다.

프로젝트 JSON에는 영상 경로, 음원 목록, 유형, 전달 방식, 프레임 구간, 볼륨, 동선 경로와 렌더링 설정이 저장됩니다.
